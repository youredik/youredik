# Эдуард Сарваров — AI-инженер

14 лет серверного кода, последний год — ИИ в рабочем продукте: поиск с цитатами по заявкам,
черновики ответов, агенты с доступом к системе. Отвечаю за продукт целиком — схема данных,
API, интерфейс, инфраструктура, выкладка. Код веду через ИИ-агентов (Claude Code),
и по каждой строке объясню решение.

**Стек:** TypeScript · Go · Python · PHP; Yandex Cloud, YDB, PostgreSQL · LLM, RAG, MCP, evals.
